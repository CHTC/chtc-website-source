GPUs (Graphics Processing Units) run very large numbers of simple calculations in parallel.
Programs written to use them, such as machine learning frameworks, image processing and some
simulations, can run ten or more times faster than on CPUs. CHTC's HTC system has shared GPUs
that any CHTC user can run jobs on, plus more capacity through backfill and the OSPool.

# The CHTC GPU Lab

{/* Moved from the retired gpu-lab page. TODO: decide how much of this to keep. */}

CHTC's shared GPUs are provided by the CHTC GPU Lab, created by a
[UW2020-funded project](https://research.wisc.edu/funding/uw2020/round-5-projects/enabling-graphics-processing-unit-based-data-science/)
to expand shared GPU computing at UW-Madison. More extended examples are in the
[GPU job templates on GitHub](https://github.com/CHTC/templates-GPUs).

The CHTC GPU Lab mailing list announces new GPU hardware and GPU-related events, asks GPU users
for feedback, and shares best practices for GPU computing at CHTC. To join, email
[chtc-gpu-lab+managers@g-groups.wisc.edu](mailto:chtc-gpu-lab+managers@g-groups.wisc.edu) and
ask to be added. The list administrators review each request.

> The CHTC GPU Lab is led by Anthony Gitter, Christina Koch, Brian Bockelman, and Miron Livny.
> The original UW2020 project was led by Anthony Gitter, Lauren Michael, Brian Bockelman, and
> Miron Livny and funded by the Office of the Vice Chancellor for Research and Graduate
> Education and the Wisconsin Alumni Research Foundation. For more information about the
> CHTC GPU Lab, contact [Anthony Gitter](https://www.biostat.wisc.edu/~gitter/index.html).
