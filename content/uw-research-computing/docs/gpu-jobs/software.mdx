Before using GPUs in CHTC, make sure that GPUs will actually make your program run faster. This
means that the code or software you are using has the special programming required to use GPUs,

CHTC's GPU servers can run Docker containers that use GPUs. If you can find or create a Docker
image with your software, you can use it to run your jobs in CHTC. See our
[Docker guide](/uw-research-computing/docker-jobs/) for how to use Docker in CHTC.

# Compiled code

You can use our usual methods of creating a portable installation of a software package (as in
our R and Python guides) to run on GPUs. Most of our build servers and GPU servers have copies of
the CUDA runtime that you can use to compile code. To get onto one of these servers, submit an
interactive job, following the instructions in our
[interactive job guide](/uw-research-computing/inter-submit/), or submit a GPU job submit file with
the interactive flag for `condor_submit`. Once on a build or GPU server, see which CUDA versions
are available by looking at the path `/usr/local/cuda-*`.

We strongly recommend software installation strategies that include the CUDA runtime in the
final installed code, so that jobs can run on servers even if a different version of the CUDA
runtime is installed (or there is no runtime at all). For compiled code, look for flags that
enable static linking, or use a container.
