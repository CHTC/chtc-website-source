This page is a minimal guide for experienced HTC users who want to start using GPUs in their
jobs at CHTC. If you are new to GPUs or to CHTC, start with
[Run your first GPU job](/uw-research-computing/gpu-jobs/first-job/).

# GPU job limits

**GPU jobs have different time limits and job number limits than jobs that only use CPUs.**

{/* TODO: confirm the "long" limit before release. It is 7 days today and is planned to drop to

| Job length | Maximum runtime | Per-user limitation |
| --- | --- | --- |
| Short | 12 hrs | 2/3 of CHTC GPU Lab GPUs |
| Medium | 24 hrs | 1/3 of CHTC GPU Lab GPUs |
| Long | 3 days | up to 4 GPUs in use |

# GPU submit file options

Add the following lines to your submit file to use GPUs and set the GPU job's characteristics:

- **Request GPUs (required)**: All jobs that use GPUs must request GPUs in their submit file (along with the usual requests for CPUs, memory, and disk). The maximum number of GPUs that can be used in one job is 4.

  ```condor
  request_gpus = 1
  ```

- **Use the CHTC GPU Lab (recommended)**: Opts your job into CHTC's shared GPUs.

  ```condor
  +WantGPULab = true
  ```

- **Specify job length (optional)**: Set the maximum duration of your job as "short", "medium", or "long", based on the runtime limits in the [table above](#gpu-job-limits). If a job is not finished by the specified time, it will be evicted and put on hold. The shorter the job length, the more jobs you can run at once. The default is "medium".

  ```condor
  +GPUJobLength = "short"
  ```

- **Run as backfill (recommended)**: Lets your job also run on research group GPUs when their owners are not using them. These jobs can be interrupted, so use this with jobs that run in a few hours or less, or that [checkpoint](/uw-research-computing/gpu-jobs/checkpointing/). See [Get more GPUs](/uw-research-computing/gpu-jobs/more-gpus/).

  ```condor
  +is_resumable = true
  ```

- **Specify GPU memory (VRAM)**: Set the minimum GPU memory *per card* your job needs. Jobs receive the full VRAM of a card, except on cards divided into smaller [MIG slices](/uw-research-computing/gpu-jobs/choose-gpu/). See the [table below](#gpus-on-our-system) for the VRAM of each card.

  ```condor
  gpus_minimum_memory = <quantity in MB>
  ```

- **Request a specific GPU hardware generation (optional)**: Some software requires certain generations of GPU hardware (called "compute capability"). You can set the minimum and maximum generations. See the [table below](#gpus-on-our-system) for the compute capability of each card.

  ```condor
  gpus_minimum_capability = <version>
  gpus_maximum_capability = <version>
  ```

- **Indicate software or data requirements using `requirements`**: If your data is large enough to use our `/staging` data system (see [Manage large data in /staging](/uw-research-computing/file-avail-largedata/)), or you are using modules or other software in our shared `/software` system, include the needed requirements.

- **Complex GPU requirements**: If your jobs have more complex requirements than the capability and memory options above, you can use the more general submit file option `require_gpus` to build a custom requirement. Contact the facilitators at chtc@cs.wisc.edu if you think you need it. See [Choose and size your GPU](/uw-research-computing/gpu-jobs/choose-gpu/).

# Sample submit file

A sample submit file is shown below. There are also example submit files and job scripts in the
[GPU Job Templates repository](https://github.com/CHTC/templates-GPUs) in CHTC's GitHub
organization. This submit file also works for
[interactive GPU jobs](/uw-research-computing/gpu-jobs/interactive/).

{/* TODO: add a container_image line once the containers section below is written. */}

<File>

```condor
# gpu-lab.sub
# sample submit file for GPU Lab jobs

universe = vanilla
log = job_$(Cluster)_$(Process).log
error = job_$(Cluster)_$(Process).err
output = job_$(Cluster)_$(Process).out

# Fill in with whatever executable you're using
executable = run_gpu_job.sh
#arguments =

should_transfer_files = YES
when_to_transfer_output = ON_EXIT
# Uncomment and add input files that are in /home
# transfer_input_files =

# Uncomment and add custom requirements
# requirements =

+WantGPULab = true
+GPUJobLength = "short"

# Also run on backfill GPUs. Jobs can be interrupted, so checkpoint
# jobs that run longer than a few hours.
+is_resumable = true

request_gpus = 1
request_cpus = 1
request_memory = 1GB
request_disk = 1GB

queue 1
```

</File>
