The software you run on a GPU, such as a language model, an image classifier, or a protein structure tool, frequently depends on a machine learning framework like PyTorch, TensorFlow, or JAX. Each release of these frameworks is built for a specific range of GPUs and needs a minimum NVIDIA driver to run. If your job lands on a machine with GPUs or drivers outside that range, it may crash with an error such as `no kernel image is available for execution on the device` or `CUDA driver version is insufficient for CUDA runtime version`. It may also run but take far longer than usual. If you are not sure which framework your software uses, check its installation instructions, its requirements file, or its model page (e.g., most Hugging Face models use PyTorch). 

In the table below, select your framework, its version, and the CUDA toolkit version you are using in the table below to see how many and what type of GPUs can run your software. Then copy the lines it gives you into your submit file, and HTCondor will only send your job to GPUs that can run it. We also provide the container image we used for testing and other notes.
