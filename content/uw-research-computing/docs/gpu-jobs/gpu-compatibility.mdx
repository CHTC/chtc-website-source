Choose what your software uses below to see which GPUs can run it, then copy the lines into
your submit file so HTCondor only matches your job to those GPUs.

<Typography variant="subtitle2" component="div" sx={{ mb: 2 }}>
Each release of a framework such as PyTorch, TensorFlow or JAX is built for a range of GPUs and needs a recent
enough NVIDIA driver. A job that lands on an older or newer GPU than its build supports fails
with errors such as `no kernel image is available for execution on the device` or
`CUDA driver version is insufficient`.
</Typography>
